Shard Workshop

Awaken the bond between male mind and female body. Spend character shards from duplicate summons to strengthen combat stats, unlock mastery, and evolve techniques. Combine surplus shards into universal fragments.

✦ Soul Awakening

Awakening +1 improves the vessel's stats. +2 strengthens its passive. +3 enhances manifested moves. +4 reduces strained-technique recoil. +5 empowers the ultimate and unlocks an animated aura.

⚔ Technique Evolution

Raise a learned move to Rank +1 or +2 using its own card's shards. Damage techniques gain power; guard techniques restore additional energy. You cannot improve an ability that the body cannot manifest.

◈ Shard Fusion

Convert four character shards into one universal Soul Fragment. Universal fragments can substitute for up to half of an Awakening cost, but cannot improve a skill. Conversions are permanent.

Install Updates

Import future SoulSwap JSON update packs directly inside the APK. The original three-card JSON export format is also accepted. Imported cards join the summon pool but are not owned until pulled. Every new card automatically supports duplicate shards, Awakening +1 to +5, skill ranks, and fusion. Existing owned cards and progress are preserved unless you restart from Settings.

Update format v2 (v1 supported)

A pack contains type: "soulswap-card-update", schemaVersion: "2.0", and a cards array. The original 1.0 format and legacy array imports still work. Each card may contain mind, body, imageBase64, prompt, and optional combat data. Legacy raw JSON arrays are accepted too.

Automatic import rule: Known card pairings keep their authored combat stats. New pairings get a deterministic starter profile that can be overwritten by fields in a future pack. The game cannot infer unseen supernatural skills from images alone.
