Update format v1

A pack contains type: "soulswap-card-update", schemaVersion: "1.0", and a cards array. Each card may contain mind, body, imageBase64, prompt, and optional combat data. Legacy raw JSON arrays are accepted too.

Automatic import rule: Known card pairings keep their authored combat stats. New pairings get a deterministic starter profile that can be overwritten by fields in a future pack. The game cannot infer unseen supernatural skills from images alone.

Offline-first. Saves stored on this device using IndexedDB and local storage.
